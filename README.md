# C Atlas

Explore a C project as a graph of functions, folders, files and header dependencies. Follow a call to its source, inspect declarations, or move blocks to arrange a graph.

- [Open the web app](https://pconst167.github.io/c-atlas/) to explore a ZIP or public GitHub repository.
- [Install the VS Code extension](vscode/README.md) to explore the open workspace, follow definitions in your editor and see the graph update as you type.
